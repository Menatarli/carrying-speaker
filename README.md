# 肩扛音响 - Carrying a speaker on the shoulder

一个 Minecraft Fabric 模组：在游戏里用一条指令让网易云音乐在后台放歌；遇到低血量、死亡这些时刻，自动播放你准备好的本地音乐。

- Minecraft 26.2 · Fabric Loader ≥ 0.19.5 · Fabric API · Java 25
- 作者：Menatarli · 许可证：CC0-1.0

## 功能

### 1. 网易云点歌（Windows + 网易云音乐 PC 客户端）

| 指令 | 作用 |
|---|---|
| `/ncm play <分享链接>` | 直接粘贴网易云的分享链接，自动判断是单曲还是歌单 |
| `/ncm song <单曲id>` | 按 ID 播放单曲 |
| `/ncm playlist <歌单id>` | 按 ID 播放歌单 |

- 支持的链接：`music.163.com/song?id=…`、`/playlist?id=…`、网页版 `#/song?id=…`、手机版 `y.music.163.com/m/…`，以及整段分享文案（会自动取出里面的链接）。短链 `163cn.tv` 暂不支持。
- **后台播放**：网易云在托盘里时，被唤起后会自动收回托盘，焦点还给游戏（全屏也可以）。如果你本来就开着网易云窗口，模组不会动它；你自己切到网易云时，也不会被弹回去。
- **冷启动**：网易云没打开时，模组会先把它启动起来，等一会儿（默认 10 秒）再补发一次播放指令。这个时候网易云会抢一下焦点。
- 歌单越大，网易云加载越慢：几百首可能要几十秒才会出声，上千首的歌单可能要两分钟。

### 2. 事件音乐（本地 mp3 / wav）

- **低血量**：血量低于设定比例时自动播放，回血到另一个比例后停止，中间不会来回反复触发。
- **死亡**：死亡时播放，优先级比低血量高，会直接打断低血量音乐。
- 每个事件可以单独设置：播哪首（或从音乐目录里随机挑）、**从第几秒起播**（比如直接从副歌开始）、**至少播多久**（回血或复活后也会放满这个时长再停）、要不要循环。
- 全部写在 `events.json` 里，改完执行 `/ncm reload` 就生效，不用重启游戏。

| 指令 | 作用 |
|---|---|
| `/ncm local play` | 从音乐目录随机播放（手动开始，不会被事件停掉） |
| `/ncm local stop` | 停止本地音乐 |
| `/ncm reload` | 重新读取配置和事件表 |

### 3. 多人点歌（OP）

| 指令 | 作用 |
|---|---|
| `/ncmop play <玩家> <分享链接>` | 给其他玩家点歌 |
| `/ncmop song <玩家> <id>`、`/ncmop playlist <玩家> <id>` | 同上，用 ID |

- 只有 OP（权限等级 2 及以上）能用。服务器控制台也能执行，此时点歌人显示为「Server」。普通玩家用 `/ncm` 给自己放就行。
- `<玩家>` 可以写玩家名，也可以用 `@a`、`@p` 这类选择器。
- **对方确认后才会播放**：对方聊天栏会出现「xx 为你点播了单曲 … [播放]」，点了绿色的 [播放] 才会播，60 秒内有效。不点就什么都不会发生。
- 被点歌的人需要装了本模组，没装的会被跳过，OP 那边会收到提示。
- 服务端也需要装本模组（单机和局域网自带，专用服务器要放进 mods 并重启）。服务端没装时，客户端的 `/ncm` 功能照常能用。

## 安装

1. 把 `carrying-speaker-1.0.0.jar` 和 Fabric API 放进 `mods` 文件夹。
2. 想用事件音乐的话，把 mp3 或 wav 放进 `config/carrying-speaker/music/`。第一次进游戏时会自动创建这个目录。
3. 想用多人点歌的话，服务端的 mods 里也要放同一个 jar。

配置说明见 [CONFIG.md](CONFIG.md)。

## 安全与隐私

- 拉起网易云使用的是它自己注册的 `orpheus://` 协议，调用方式和原版点击聊天链接一样。模组不注入网易云、不读它的内存、不模拟按键，也不碰你的网易云账号。
- 你粘贴的链接不会被直接打开。模组只从里面取出类型和数字 ID，再自己拼出播放链接。
- 多人点歌的网络包里只有「类型 + 数字 ID + 点歌人名字」，接收方会再校验一遍。客户端从不主动给服务器发包。
- 窗口方面只做一件事：把被我们唤起的网易云窗口收回托盘。除此之外不改动任何别的程序。

## 已知限制

- 网易云相关功能只支持 Windows。本地事件音乐不受这个限制。
- 用 `/ncm local play` 手动开的音乐，退回主菜单时不会自动停。
- 非 OP 玩家（以及没开作弊的局域网房主）不能用 `/ncmop`。

## 旧版本升级

从旧版（文件名是 `ncmplayer-1.0.0.jar`）升级时，记得**删掉旧 jar** 再放新 jar。第一次启动时，模组会把旧的 `config/ncmplayer.json` 和 `config/ncmplayer-music/` 复制到新目录 `config/carrying-speaker/`，旧文件原样保留。服务端和客户端需要同时升级。

## 从源码构建

需要 JDK 25。在工程根目录执行：

```
./gradlew build
```

产物在 `build/libs/carrying-speaker-1.0.0.jar`。
